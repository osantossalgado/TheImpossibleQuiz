📦 How to Deploy on GitHub Pages

  1. Create a new repository on GitHub (Public repository recommended).
  2. Save this code as index.html in the main directory.
  3. Upload your SWF file to the same repository folder and rename it to the-impossible-quiz.swf (or update the filename in the script below).
  4. Go to your repository Settings → Pages, set the source branch to main (or root), and save.
  5. Share your GitHub Pages link with students! They can play smoothly without ads or distractions.
